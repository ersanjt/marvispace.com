# Contributing

Thanks for contributing to MARVISPACE.

## Development principles

- keep storefront behavior fast and dependency-light
- preserve bilingual routing and SEO behavior
- never commit production secrets or `.env` files
- document changes that affect PHP/MySQL deployment
- prefer focused pull requests over broad rewrites

## Pull requests

Include:

- what changed and why
- testing notes
- screenshots for visible changes
- database or deployment implications
- any security considerations

Before submitting, review [SECURITY.md](SECURITY.md) and verify that no credentials, private customer information, or production configuration were added.
